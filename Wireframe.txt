# Wireframe

## 1. 记录页

### 页面目标
让用户最快完成一次练舞记录，并能看到最近记录。

### 顶部
- 页面标题：暂定“练舞记录”
- 本周累计：3次 · 约3h
- 本月累计：8次 · 约5.8h

### 主操作
[ + 记一次练舞 ]

点击后进入记录表单。

### 记录表单
字段：

- 日期
  - 默认今天

- 本次练习时长
  - 20 / 30 / 45 / 60 / 90
  - 自定义

- 今天做了什么
  - 多选
  - 基本功
  - 体能
  - 自学成品舞
  - 上课
  - 编舞
  - Freestyle
  - 拍摄
  - 发布作品
  - 其他

- 舞种
  - 多选
  - 使用 DATA_MODEL.md 中 dance_style

- 具体内容

  示例：
  - 中段基本功
  - 臀部基本功
  - 手臂协调
  - 副歌
  - 脚步
  - clean
  - freestyle

  - 系统可根据用户过去填写过的内容提供历史补全建议

- 关联目标
  - 可选
  - 显示当前 active Goals

- 备注
  - 可选，一句话

按钮：
[ 保存记录 ]

### 最近记录

每条记录显示：

日期
45 MIN
HIPHOP / BASIC
Footwork · Groove

点击后查看详情 / 编辑。

### 两种查看方式

[ 日期 ] [ 阶段 ]

日期：
按日期倒序查看。

阶段：
按 Goal 查看相关 PracticeRecord。

## 2. 目标页

### 页面目标
创建和管理阶段性练舞目标。

### 顶部
当前进行中的目标。

[ + 新建目标 ]

### 新建目标

字段：

- 周期
  - 开始日期
  - 结束日期
  或
  - xx天

- 内容类型
  - 使用 activity_type

- 舞种
  - 使用 dance_style

- 重点内容
  - 可选
  - 自由填写
  - 用于描述这个阶段最想集中练的内容
  - 不要求从固定标签中选择

  示例：
  - 中段基本功
  - 臀部基本功
  - 手臂协调
  - Hiphop脚步
  - 编舞
  - 副歌clean
  - 上肢控制

  - 系统可根据用户过去填写过的内容提供历史补全建议

- 目标描述
  - 例如：
    “最近3天集中练 Hiphop 脚步”

- 可选量化
  - 目标数量
  - 单位

按钮：
[ 开始这个阶段 ]

### Goal 卡片

显示：

HIPHOP FOOTWORK
7 DAYS

Oct 05 — Oct 11

3 sessions · 125 min

状态：
active / paused / completed

点击进入详情。

### Goal 详情

显示：
- 目标信息
- 累计练习次数
- 累计练习时长
- 相关记录
- 完成 / 暂停

## 3. Shuffle 页

### 页面目标
当用户不知道练什么时，给一个轻量建议。

### 输入

今天能练多久？

[ 20 ] [ 30 ] [ 45 ] [ 60 ] [ 90+ ]

### 主按钮

[ SHUFFLE ]

### 结果

TODAY'S PICK

HIPHOP
Footwork

30–45 MIN

“最近几次主要在练成品，
今天可以换点脚步基本功。”

可选搭配：
Groove / Freestyle

按钮：

[ 就练这个 ]
[ 再换一个 ]
---

## 页面关系

记录页
→ 新建记录
→ 记录详情

目标页
→ 新建目标
→ 目标详情
→ 查看阶段记录

Shuffle
→ 推荐结果
→ 点击“就练这个”
→ 进入新建记录，并预填推荐内容
